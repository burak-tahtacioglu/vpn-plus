# VPN+ GitHub Pages

This folder is a dependency-free static site for the VPN+ App Store privacy and support URLs.

## Publish

1. Create a public GitHub repository (for example `VPNPlus`).
2. Copy the contents of this `GitHubPages` folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

Expected URLs when the repository is named `VPNPlus`:

- Website: `https://buraktahtacioglu.github.io/VPNPlus/`
- Privacy Policy: `https://buraktahtacioglu.github.io/VPNPlus/privacy.html`
- Support URL: `https://buraktahtacioglu.github.io/VPNPlus/support.html`

If the GitHub username or repository name differs, update the support-request URL near the bottom of `support.html` before publishing.

The policy must be reviewed whenever the app adds analytics, advertising, accounts, cloud storage, a developer-operated VPN service or other data processing.
